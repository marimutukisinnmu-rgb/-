# LAN Territory Battle

2〜10人で遊ぶLAN対戦バカゲー。

## 現在の仕様

- Node.js + WebSocket
- CPUなし、全員プレイヤー
- LAN上のブラウザから参加
- プレイヤーは常に前進
- A / D または ← / → で方向転換
- 押している間は0.01秒間隔で15°ずつ回転
- 60 FPSでゲームを更新
- 歩いた場所を自分のインクで塗る
- 領土が0になったプレイヤーは脱落
- 水色ボタン「雨」でインクが溶け、各プレイヤーの本拠地1マスだけ残る

## 起動

```powershell
npm install
npm start
```

サーバーPCのIPアドレスを確認して、同じLAN内の各PCから次へアクセスします。

`http://サーバーPCのIP:8080/`
